How it works

Each GenBank file becomes one plasmid in the selected destination project.

Weaver stores the original GenBank file as the plasmid sequence file, so the plasmid viewer can render annotated features directly.

If you create a new project here, Weaver will switch your current project to it after import.

When YTK-like restriction site annotations are present, Weaver can infer a conservative subset of metadata such as resistance marker, type, and level.
