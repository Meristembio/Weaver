# Sticta Major Update

Historical notes for the latest major Sticta update.

## Scope

This stage expanded verification, sequence analysis, laboratory services, and construct workflow support. The current behavior is described in the linked feature pages, while this page records the change areas without presenting them as a dated release.

## Documented Changes

- Multiple-file Sanger processing with AB1, PHD.1, and SEQ inputs and persisted verification runs.
- Alignment review, chromatogram inspection, quality regions, variants, and manual verification decisions.
- OVE-integrated primer matching, amplicon filters, map annotations, sequence copying, and local BLAST handoff.
- OVE-integrated restriction digest planning with buffer and temperature constraints.
- Primer3-backed primer dimer analysis.
- Batch plasmid and glycerol-stock label printing.
- ReactFlow experiments map support.

These capabilities remain subject to the routes, permissions, formats, and limitations documented under `docs/features/`. Historical scope should not be treated as a promise that an older interface or implementation detail is unchanged.
