# Original Repository

Historical notes for the original Meristem Weaver repository.

## Scope

The original stage established the Django and React application structure and the early DNA design and inventory workflows. The repository documentation from that stage referenced plasmid and glycerol-stock table modules, an assembly wizard, and a Level 0 Designer.

## Historical Capabilities

- DNA design and management through a Django backend with React modules.
- Plasmid and glycerol-stock inventory tables.
- Early assembly wizard and Level 0 design references.

This page does not assert that every original route or frontend behavior remains available in the current Sticta checkout. For current instructions, use the pages under `docs/features/`.
