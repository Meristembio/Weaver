# Current Weaver Documentation

This is the entry point for documentation of the current Weaver codebase. Weaver is a Django application for biological construct inventory, sequence visualization, construct design, verification, and laboratory support services. The [repository README](../README.md) covers installation and local setup; these pages explain the user-facing workflows.

## Suggested Reading Order

1. Start with [Inventory](features/inventory.md) to understand authentication, projects, permissions, plasmids, stocks, primers, and restriction enzymes.
2. Read [Plasmid Design](features/plasmid-design.md) when creating a construct, and [Sequence Visualization](features/sequence-visualization.md) when a sequence file is available.
3. Use [PCR and Primers](features/pcr-and-primers.md), [Restriction Analysis](features/restriction-analysis.md), and [Sanger Verification](features/sanger-verification.md) to check a construct.
4. Review [Supported Formats](features/supported-formats.md) before uploading sequence, primer, alignment, or trace files.
5. Use [Services](features/services.md) and [Protocols](features/protocols.md) for workflows that span multiple inventory records or describe laboratory preparation.
